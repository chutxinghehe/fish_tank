# ESP32 Smart Fish Tank

ESP32-based aquarium monitoring and automation system
developed using Arduino IDE and FreeRTOS.

## Technologies
- ESP32, Embedded C/C++
- FreeRTOS (Tasks, Mutex, Queue)
- ADC, I2C, Wi-Fi, HTTP
- Sensors, Relays, Servo Motor

## Features
- Water temperature, level and TDS monitoring
- Sensor filtering (Median, EMA)
- Hysteresis-based pump control
- Automated feeding
- OLED display and Telegram alerts
